# Support Ticket Classification using Machine Learning

## Project Overview
This project focuses on automatically classifying customer support tickets into different categories using Machine Learning and Natural Language Processing (NLP) techniques.

## Objective
The main objective of this project is to automate the classification of support tickets and improve customer support efficiency.

## Dataset Information
The dataset contains support tickets categorized into the following classes:
- Account
- Billing
- General
- Security
- Technical

Total records: 13,500+

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- VS Code
- GitHub

## Methodology
1. Data Collection
2. Data Preprocessing
3. Feature Extraction using TF-IDF
4. Train-Test Split
 5. Model Training
6. Prediction
7. Performance Evaluation

## Model Used
- Logistic Regression

## Performance Evaluation
The model performance was evaluated using a confusion matrix and achieved high classification accuracy.
